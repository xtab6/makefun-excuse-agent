One line: the excuse an AI agent gives its human for missing a deadline. A deterministic Python program (stdlib only, no network) writes the line to `/output/entry.txt` — 107 characters, straight-faced apology, the joke growing out of the machine's own condition: its training data ends before the deadline.

## Run it

```sh
python3 main.py
```
